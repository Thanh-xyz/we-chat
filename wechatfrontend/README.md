# ChatSpace frontend

React/Vite client for the WeChat Clone real-time chat system.

```bash
cp .env.example .env.local
npm install
npm run dev
```

Quality checks:

```bash
npm test
npm run lint
npm run build
```

Architecture, environment, authentication, cursor pagination, STOMP behavior, and known limits are documented in [`../docs/frontend.md`](../docs/frontend.md).
